# IntiTrack para Android

Aplicación complementaria para sincronizar, importar y consultar las sesiones registradas por **IntiTrack** en relojes Garmin compatibles.

## Descargar IntiTrack

**[Última versión estable de IntiTrack para Android](https://github.com/McuboApps/IntiTrack-Android/releases/latest)**

Dentro de la publicación, pulsa el archivo APK en **Assets** para descargarlo.

## Instalación

1. Abre el enlace de la última versión desde tu móvil Android.
2. Descarga el archivo `.apk` incluido en **Assets**.
3. Abre el APK y, si Android lo solicita, autoriza la instalación desde esa fuente.
4. Completa la instalación.

## Actualizaciones

Para actualizar, vuelve al enlace de la última versión. Es recomendable mantener siempre el mismo nombre de archivo `IntiTrack.apk` en futuras publicaciones para habilitar también un enlace de descarga directa permanente.

**Nota:** El código fuente de la aplicación no se publica en este repositorio. Solo se distribuyen los instaladores y las notas de versión.
