# IntiTrack para Android

Aplicación complementaria para sincronizar, importar y consultar las sesiones registradas por **IntiTrack** en relojes Garmin compatibles.

## Descargar

Las versiones oficiales de Android se publican en la sección **[Releases](https://github.com/McuboApps/IntiTrack-Android/releases)**.

> La primera versión todavía no está publicada. El enlace de descarga se habilitará cuando se adjunte el archivo `IntiTrack.apk` a una versión estable.

## Instalación

1. Abre la última versión estable desde **Releases** en el móvil Android.
2. Descarga el archivo `IntiTrack.apk`.
3. Abre el APK y, si Android lo solicita, autoriza la instalación desde esa fuente.
4. Completa la instalación.

## Actualizaciones

Para mantener un enlace permanente de descarga, todas las versiones estables usarán el mismo nombre de archivo: `IntiTrack.apk`.

**Nota:** El código fuente de la aplicación no se publica en este repositorio. Solo se distribuirán los instaladores y las notas de versión.
